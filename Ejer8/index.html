RAT Ontological Archive


RAT Ontological Archive es una plataforma web para escritores y creadores de mundos que permite organizar historias, personajes, documentos, proyectos, imágenes, videos y lore en un solo lugar. Funciona como una mezcla entre wiki narrativa, gestor de archivos creativos y foro comunitario, permitiendo crear proyectos privados o públicos, documentar universos ficticios y compartir textos con otros usuarios.
La web cuenta con perfiles, sistema de publicaciones, comentarios, likes, almacenamiento multimedia y conexión a servidor real, pensada para guardar información de forma más segura y permitir el acceso desde distintos dispositivos. Su estilo visual combina una estética oscura, sci-fi y minimalista, inspirada en archivos digitales y sistemas de registro futuristas.
